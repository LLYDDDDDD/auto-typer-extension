光标自动打字 · Chrome / Microsoft Edge 浏览器扩展

安装（只需要一次）
1. 如果下载的是 ZIP，先解压到一个固定文件夹。
2. Edge：在地址栏输入 edge://extensions 并回车。
   Chrome：在地址栏输入 chrome://extensions 并回车。
3. 打开“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择这个包含 manifest.json 的文件夹。
5. 在浏览器工具栏的扩展菜单中，将“光标自动打字”固定到工具栏。

使用
1. 复制想输入的文字，然后切换到目标网站。
2. 点击工具栏里的“光标自动打字”。按 Ctrl+V 粘贴，或点击“读取剪贴板”。
3. 设置速度和准备时间（默认 20 字/秒、3 秒）。
4. 点击“开始输入”，弹窗自动关闭；在倒计时内点击目标输入框，放好光标。
5. 文字会从光标位置逐字输入。如果已经选择一段文字，会先替换选中的文字。
6. 按 Esc 或 Alt+Shift+X 停止。也可以重新打开扩展点击“停止”。
7. 要向另一个网页输入，切换到那个网页，再启动扩展即可。

测试
可以用附带的“测试网页.html”。扩展默认用于 HTTP/HTTPS 网站。
若要在本地 HTML 测试：进入扩展详情，打开“允许访问文件网址”，
然后用浏览器打开附带的“测试网页.html”。

支持范围
- 普通文本框、搜索框、多行文本框，以及使用 contenteditable 的常见富文本编辑器。
- 中文、表情和换行；单行输入框内的换行会变为空格。
- 输入过程中离开输入框、切换标签页、刷新或关闭页面都会停止。
- 输入期间请保持目标编辑框聚焦，避免打开弹窗或切换应用。
- 只能输入文字，不会模拟 Enter 提交消息。
- 密码框、数字框、浏览器设置页、新标签页和扩展商店不支持。
- 某些特殊编辑器会拦截输入；跨域 iframe 内的编辑框可能需要单独打开其网页。
- 这是网页编辑操作，不是操作系统层面的物理键盘；不保证支持要求真实按键的网站。
- 此扩展不控制桌面软件。

隐私
不联网，不上传文字。文字草稿仅保存在浏览器会话中，结束浏览器会话后清除。
输入速度和准备时间保存在本地。仅在你启动扩展时获得当前标签页的访问权限。
“读取剪贴板”按钮需要浏览器授予剪贴板读取权限。

如果快捷键无效
在 edge://extensions/shortcuts 或 chrome://extensions/shortcuts 检查快捷键冲突。
